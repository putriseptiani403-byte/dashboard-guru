📋 Cara kerja dashboard

1. Peserta didik
Mengerjakan game dari file HTML masing-masing.
2. Firebase
Hasil dikirim ke Realtime Database secara live.
3. Dashboard Guru
Menu membaca data yang sama dan memperbarui tampilan otomatis.

🗑️ Reset Data

Gunakan saat ingin mengosongkan data peserta didik di Dashboard untuk memulai sesi/kelas baru.

⚠️ Perhatian: tombol ini menghapus seluruh data pada mathflow/students dari Firebase. Data yang sudah dihapus tidak dapat dipulihkan dari Dashboard.
💡 Reset di sini menghapus data yang tersimpan di Firebase. Jika peserta didik masih memiliki progres lama yang tersimpan di browser mereka, progres lokal tersebut dapat muncul kembali ketika game menyimpan data lagi.
